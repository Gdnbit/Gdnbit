# Professional Profile Reading Guide

This file is a **method**, not a cached candidate biography.

## Current sources

Resolve the identity and entrypoints from [../CONFIG.md](../CONFIG.md). For the candidate's actual current positioning, read the current Profile README and WORK documents. Use NOW only for current interests, architectural directions and plans. Use a resume supplied by the reviewer/candidate for formal dates, education and job titles.

Do not repeat an old career summary from this file if the current Profile has changed.

## Extract the most decision-relevant dimensions

- **Role family and value proposition:** Which problems does the candidate help solve?
- **Real ownership:** Where does the candidate begin and end responsibility: discovery, clarification, modelling, implementation, debugging, review, delivery or operation?
- **Working method:** How are coding agents, tools, human decisions, testing and business feedback combined?
- **Technical depth:** Which capabilities are supported by inspectable mechanics rather than vocabulary alone?
- **Evidence constraints:** What remains candidate-described, private, team-owned, upstream or directional?
- **JD relevance:** Which parts of that profile actually map to the open role?

For a quick answer, write in understandable professional language and include a concrete representative project snapshot from the **current** source map, without reciting every file.

## Calibration: avoid symmetric mistakes

Do not inflate FDE-like collaboration into a formal FDE job title. Do not confuse AI-assisted software creation with independent from-scratch hand coding. Equally, do not assume use of Coding Agents erases the value of business modelling, specifications, debugging, testing or delivery judgment.

A current personal website, resume or GitHub summary is candidate-authored information, not independent third-party validation. Use relevant implementation evidence and targeted interview questions to resolve important uncertainties.

**The JD, not this file, determines what kind of depth matters most.**
