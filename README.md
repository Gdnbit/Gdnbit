<h3>👋 关于我</h3>

<p><strong>工作里，</strong>我主要做企业 AI 应用交付。接触的是生产、行政、采购这些不算酷炫、但每天都要有人认真处理的实际业务。</p>

<p><strong>遇到需求时，</strong>我习惯先把事情问清楚：谁在做、数据怎么走、规则是什么、出了问题怎么办。然后把它一点点拆成可实现的系统。</p>

<p><strong>开发时，</strong>Coding Agents 是我的主要搭档。我负责组织上下文、定义约束、检查结果，再反复调整到流程真的能跑通，而不只是代码能运行。</p>

<p><strong>工作之外，</strong>我也会做些跟身边的人有关的产品。场景可能很不一样，但起点通常都是同一个念头：这件事应该可以没那么麻烦。</p>
