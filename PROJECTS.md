## Project themes

### Personal agents & agent-native products

I am interested in software where an agent has durable state, memory, skills and permissioned tools — and can make progress across sessions instead of behaving like a stateless chat box.

### Agent runtime & tool use

The useful layer is increasingly the runtime around the model: tools, MCP, skills, execution state, permissions, approvals, observability and recovery.

### Evidence & memory

For systems that need to be trusted, answers are not enough. I care about provenance, evidence, durable memory, revision history and the ability to reconstruct why an action or decision happened.

### AI-native software delivery

I use coding agents heavily and treat specifications, contracts, tests and repository context as part of the development interface. The goal is not to maximize manually typed code; it is to ship systems whose behavior can be understood, evaluated and iterated.
