02 / HOW I WORK

从模糊需求，
到可验证的系统。

我更擅长把问题理解清楚、把系统边界定义清楚，再让 Coding Agents 成为实现与迭代过程中的真实协作者。

我的完整工作方式 →
01

理解问题，而不只是接收需求

补齐业务规则、输入输出、状态、角色、权限与异常场景，识别系统真正要解决的约束。

02

把业务逻辑转译为开发接口

拆解任务，定义数据和 API 契约、验收标准与上下文，让 Agent 可以持续推进实现。

03

让验证与交付形成闭环

通过测试、实际流程联调、反馈迭代与结果检查，判断方案能否解决真实问题。

AI-native 不是把代码全部交给 AI 就结束了；更重要的是，人能够维护问题定义、上下文、约束和评价机制。
03 / WHAT'S NEXT

不只为软件
加一个 AI 功能。

我更关心的是：当 Agent 真正进入组织，能够读取状态、调用能力、遵守权限、推进流程，并把结果持续沉淀，软件本身应该变成什么样？

Custom Delivery → Reusable Capabilities
→ Enterprise Context & State
→ Tools, Permissions & Agent Runtime
→ AI-native Systems
